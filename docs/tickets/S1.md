# S1 : Setup Angular et premier composant

**Branche** : `feature/s1-edition-card` | **Durée** : 2 à 3 h | **Copilot** : désactivé

## Contexte

Le Capitole veut une console de supervision (voir `docs/client-brief.md`). On commence par l'écran le plus simple : afficher une édition sous forme de carte. Aucun appel au backend dans ce ticket : les données sont écrites en dur.

## Travail demandé

1. Créer l'application dans `frontend/` avec Angular CLI (`ng new frontend`), styles CSS, sans SSR. Accepter les valeurs par défaut pour le reste. Lancer `ng serve`.
2. Lire les fichiers générés (`main.ts`, `app.config.ts`, `app.ts`, `app.html`) et comprendre le rôle de chacun.
3. Écrire **à la main** dans `src/app/` un fichier `edition.model.ts` qui contient :
   - un type `EditionStatus` : union de littéraux `'STARTED' | 'COMPLETED' | 'FAILED'` ;
   - une interface `Edition` avec `id`, `label`, `status`, `startTime`, `endTime` (peut être `null`), `tributeCount`, `aliveCount`, `eliminatedCount`, `errorCount`.
   Les noms et types viennent de `GET /api/editions` (voir `docs/domain-model.md`).
4. Créer un composant `EditionCard` avec `ng generate component edition-card`. Il affiche le label, le statut, les dates, le nombre de tributs vivants et éliminés.
5. Dans `app.ts`, déclarer un objet `Edition` en dur (reprendre l'édition 74 de `docs/domain-model.md`) et l'afficher avec `<app-edition-card>`.
6. Le composant reçoit l'édition via un `input()` signal (pas de décorateur `@Input`).
7. Afficher la date de fin uniquement si elle existe, avec `@if`. Sinon afficher « En cours ».
8. Colorer le statut selon sa valeur (vert, orange, rouge) avec une classe CSS dynamique.

## Critères d'acceptation

- [ ] `ng serve` démarre sans erreur ni warning.
- [ ] `strict` activé, aucun `any`.
- [ ] Le composant est standalone, utilise `input()` et `@if`.
- [ ] Changer le `status` en dur change la couleur de la carte.
- [ ] Mettre `endTime` à `null` affiche « En cours ».

## Pièges connus

- `input()` est un signal : dans le template on écrit `edition().label`, avec les parenthèses.
- Un tutoriel ou une IA peut vous montrer `*ngIf` ou `@Input()` : c'est l'ancienne syntaxe, ne l'utilisez pas.
- Les dates arrivent du backend en chaîne ISO 8601 : gardez `string` dans le modèle pour ce ticket. Le pipe `date` s'en charge à l'affichage.
- Ne créez pas de `NgModule`.

## À comprendre avant la revue (vous devez pouvoir l'expliquer)

1. Quelle différence entre un `type` union et une `interface` ?
2. Pourquoi `input()` s'appelle comme une fonction dans le template ?
3. Que fait `ng serve` quand vous sauvegardez un fichier ?
