# Déroulé d'une session

1. **Ticket** : lu dans `docs/tickets/`. Contexte, critères d'acceptation, pièges.
2. **Dev** (2 à 3 h) : branche `feature/sN-...`, code écrit à la main.
3. **Revue** : push de la branche, revue de code au format PR (`[bloquant]`, `[suggestion]`, `[nit]`).
4. **Correction** : application des remarques, puis explication des écarts avec la solution de référence.
5. **Rétro** : 3 lignes dans `docs/retro.md` : ce qui a bloqué, ce qui a été appris, ce qui reste flou.

## Règles

- Copilot désactivé pendant S1, S2 et S3. Réactivé ensuite, uniquement en tuteur (explications, relecture).
- Chaque suggestion de Copilot se vérifie sur https://angular.dev.
- Pas de copier-coller d'un bloc que vous ne savez pas expliquer ligne par ligne.
